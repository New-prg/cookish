# Offline-first рацион с синхронизацией аккаунта

Статус: заменён [ADR-0002](0002-server-primary-phone-cache.md) 2026-10-11.

Cookish сохраняет локальную работу с Рационом и Историей питания без аккаунта и сети. Backend предоставляет аккаунты, синхронизацию, шеринг и биллинг. Если при первом входе локальный и серверный Рационы различаются, пользователь выбирает исходный вариант. После выбора Cookish синхронизирует данные и при конфликте отдаёт приоритет локальной копии. Это решение усложняет синхронизацию, но сохраняет офлайн-доступ и накопленные локальные данные.

# Источники каталога продуктов

Дата проверки: 3 августа 2026 года.

## Вывод

Публичные витрины «Пятёрочки», «Магнита», «Ленты» и «О’КЕЙ» подходят для ручной сверки ассортимента, но у сетей не найдено документированного публичного API с разрешённым массовым получением карточек. Их внутренние endpoints привязаны к магазину, региону, сессии и могут измениться без предупреждения. Подключать такие endpoints напрямую к мобильному приложению рискованно: интеграция будет нестабильной и может нарушать условия использования площадки.

- «Магнит»: публичный каталог показывает ассортимент, цены и фасовки — <https://magnit.ru/catalog>.
- «Лента»: публичный каталог с категориями и карточками — <https://lenta.com/catalog/>.
- «Пятёрочка»: официальный каталог собственных марок и переход в доставку — <https://brands.5ka.ru/>. Ассортимент зависит от региона.
- «О’КЕЙ»: публичная витрина сети — <https://www.okmarket.ru/>; документированный API для выгрузки каталога не опубликован.

Поэтому каталоги сетей стоит подключать только через официальное партнёрское соглашение или через отдельный серверный импорт с письменным разрешением, мониторингом схемы и привязкой к конкретному магазину. Название сети, SKU, штрихкод, цена, регион, магазин и время получения должны храниться раздельно; цена не является свойством пищевого продукта.

## Рекомендуемая база пищевой ценности

1. **Open Food Facts** — лучший первый источник для товаров российского рынка и поиска по штрихкоду/названию. API отдаёт ингредиенты и пищевую ценность, актуальная версия для новых интеграций — v3: <https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/>. Нормализованные поля на 100 г/порцию описаны в схеме продукта: <https://openfoodfacts.github.io/documentation/docs/Product-Opener/schemas/schemas/product/>. База распространяется по ODbL, изображения — по отдельной CC BY-SA лицензии, поэтому нужны атрибуция и соблюдение условий: <https://openfoodfacts.github.io/openfoodfacts-server/api/tutorials/license-be-on-the-legal-side/>.
2. **USDA FoodData Central** — надёжный справочник для общих продуктов, витаминов и минералов. REST API предоставляет поиск и подробную карточку; необходим ключ data.gov, данные опубликованы как CC0: <https://fdc.nal.usda.gov/api-guide/>. Для русских торговых марок покрытие слабее, поэтому это второй источник.

## Предлагаемая промышленная схема

Мобильное приложение должно искать мгновенно в локальном индексе. Серверная задача периодически загружает разрешённые источники, приводит единицы к значениям на 100 г/мл, объединяет записи по GTIN/штрихкоду и публикует версионированный компактный индекс. Приоритет: карточка пользователя → Open Food Facts по штрихкоду → общий продукт FoodData Central → ручной ввод. Для каждого значения сохраняются источник, дата обновления и признак «с этикетки» или «усреднённое».

Текущая версия приложения реализует безопасный первый этап: встроенный офлайн-справочник общих продуктов, подсказки из него и пользовательской базы, автоматическое создание продукта из запроса, хранение калорийности, БЖУ, клетчатки, витаминов и минералов. Она не копирует каталоги торговых сетей и не зависит от их закрытых интерфейсов.

Проверено 3 августа 2026 года небольшим числом запросов, без массовой выгрузки.

Успешно проверенные Open Food Facts запросы:

- поиск: `https://world.openfoodfacts.org/cgi/search.pl?search_terms=молоко&search_simple=1&action=process&json=1&page_size=3&fields=code,product_name,brands,nutriments,categories_tags`;
- карточка: `https://world.openfoodfacts.org/api/v2/product/4607053473544.json?fields=code,product_name,brands,nutriments,ingredients_text_ru,categories_tags`.

Карточка `4607053473544` вернула название «Молоко Простоквашино 2,5%», бренд, состав, энергию, белки, жиры и углеводы. Практический следующий шаг — добавить Open Food Facts как асинхронный второй уровень подсказок после локального индекса. Каталоги сетей можно оставить как кандидатов на серверный импорт, но не вызывать из WebView: факт успешной загрузки внутри браузера не означает разрешение или техническую возможность повторять запрос из приложения.

### Проверка штрихкода и цен

Штрихкод `4605035006964` найден в Open Food Facts как «Вода минеральная Псыж газ». Карточка содержит название и категорию природной минеральной воды, но не содержит заявленных изготовителем БЖУ и состава. При импорте неполная карточка не должна стирать уже заполненные пользователем значения.

Цены находятся в отдельном проекте Open Prices и запрашиваются через `GET https://prices.openfoodfacts.org/api/v1/prices?product_code={штрихкод}`. На момент проверки API отвечал `200` и разрешал origin приложения, но для `4605035006964` и `4607053473544` вернул `total: 0`. Если цены появятся, необходимо показывать цену вместе с валютой, датой и торговой точкой; переносить её в продукт как постоянное значение нельзя.

### Поиск по названию в приложении

В форму создания запроса добавлен асинхронный поиск Open Food Facts. Он запускается после трёх символов, запрашивает до восьми карточек, подмешивает их после пользовательских товаров в системные подсказки и кэширует результат на время работы приложения. При выборе карточки в локальный продукт переносятся название, бренд, GTIN, категория, единица, состав и доступная пищевая ценность. Ошибка сети не блокирует создание товара вручную.

Новый полнотекстовый Search-a-licious (`POST https://search.openfoodfacts.org/search`) успешно отвечает на запросы, но при проверке не вернул `Access-Control-Allow-Origin`, поэтому прямой вызов из Android WebView был бы заблокирован политикой браузера. Клиент временно использует совместимый официальный поиск `cgi/search.pl`; вызов изолирован в отдельной функции для последующей замены на Search-a-licious через серверный прокси или после появления подходящего CORS-контракта.

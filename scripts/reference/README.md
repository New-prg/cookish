# Встроенный справочник общих продуктов

Справочник КБЖУ общих продуктов без марки (#63): крупы, овощи, фрукты, мясо,
рыба, молочные продукты, яйца, масла, хлеб, орехи. Работает без сети. Им
пользуется Заполнитель через `find_reference` (#64); `id` записи — это
`source_ref` в `upsert_product`.

- `foods.mjs` — список: `id`, русское название, категория, единица и `fdc_id`
  записи USDA FoodData Central, SR Legacy.
- `build-reference.mjs` — сборка: `node scripts/reference/build-reference.mjs [--list]`.
  Скачивает выгрузку SR Legacy (CSV, CC0, ключ не нужен) в `output/reference/`,
  сверяет SHA-256 архива, пишет `mobile-shell/services/catalog/reference-foods.js`.
  Повторный запуск на той же выгрузке даёт тот же файл. `--list` печатает
  записи с исходными описаниями USDA для проверки.
- `russian-sample.mjs` — выборка для сверки с российскими таблицами.

## Соглашения

- КБЖУ на 100 г (для единицы «л» — на 100 мл, как на 100 г).
- Углеводы — усвояемые: «по разности» USDA минус клетчатка, как на российских
  этикетках и в Open Food Facts. Клетчатка отдельно; где USDA её не знает — `null`.
- Каждая запись проходит проверку карточки `mobile-shell/core/nutrition-check.js`:
  - есть калории, белки, жиры и углеводы;
  - 4·Б + 9·Ж + 4·У + 2·клетчатка сходится с калориями в пределах ±15%
    (±20% при клетчатке от 3 г);
  - не больше 900 ккал;
  - Б+Ж+У не больше 100 г (с запасом 0,5 г на округление).
- Единицы только «г» и «л»: у «шт.» нет веса, и КБЖУ по ней не считаются.

## Что не вошло

- **Не прошли проверку карточки:**
  - отруби овсяные и пшеничные: USDA даёт 246 и 216 ккал, а по Б/Ж/У выходит 366 и 274 — особые коэффициенты энергии;
  - лимон, лайм, уксус: калории дают органические кислоты, которых нет в Б/Ж/У;
  - смалец: 902 ккал.
- **Сбивает модель:** американский зернёный творог (cottage cheese). На запрос «творог» модель брала его вместо обычного творога, а у них разный белок. Без этой записи «творог» уходит в Open Food Facts, где кандидаты с разной жирностью дают вопрос человеку (#64).
- **Нет честного аналога в USDA:** творог, ряженка, кефир 2,5% и 3,2%, сметана 15%, молоко 2,5%, бородинский хлеб, российские сыры. Американские замены расходятся с российскими таблицами по белку и жиру в 1,5–2 раза. Такие продукты Заполнитель ищет в Open Food Facts или оценивает через Предложение. Пополнять справочник будем по журналу ненайденных названий (#65).

## Сверка с российскими таблицами

Сверочных пар — 38. Значения взяты из базы health-diet.ru: её страницы ссылаются на «Скурихин И.М. и др. Химический состав пищевых продуктов». Это вторичный источник, он используется только для сверки и в данные не попадает. Расхождений больше 15% (и больше 10 ккал или 1,5 г) — 18, все разобраны:

| Продукт | Расхождение | Решение |
|---|---|---|
| Манная крупа | Б 12,7 / 10,3 | USDA — семолина из твёрдой пшеницы. Запись переименована в «Манная крупа из твёрдой пшеницы» |
| Хлеб белый | Ж 3,3 / 0,8 | В американском белом хлебе есть жир и сахар. Запись переименована в «Хлеб белый тостовый» |
| Груша | ккал 63 / 47 | Сорт bartlett заменён общей записью «Pears, raw»: 57 ккал, осталось только У +17% |
| Чечевица, треска | ккал +19% | Другая влажность и метод расчёта энергии. Карточка USDA проходит проверку — оставлена |
| Свёкла, баклажан, яблоко, клубника | У ±16–36% при близких ккал | Сорт и метод определения сахаров — оставлены |
| Грецкий орех, миндаль, фундук, арахис | У −23–37% | Российские таблицы считают углеводы орехов иначе; ккал совпадают в пределах 5% — оставлены |
| Говяжья вырезка | Ж 5,7 / 2,8, ккал +31% | Американская говядина мраморнее — оставлена, отличие известно |
| Свиная вырезка | Ж 2,2 / 7,1, ккал −23% | Американская свинина постнее — оставлена |
| Горбуша, яйцо, перепелиное яйцо | Ж −15–32% | Сезон и корм, ккал в пределах 15% — оставлены |

Ты собираешь приложение для человека из набора готовых кубиков. Всё, что нужно знать, написано в одном файле.

1. Прочитай файл `{{dir}}/prompt.md` целиком. В нём правила набора, примеры, описание пространства человека и в конце его запрос. Больше ничего в репозитории не читай и не ищи: ни другие файлы, ни код, ни другие папки.
2. Запиши ответ в файл `{{dir}}/answer.{{ext}}`. В файле только сам ответ в том виде, который описан в prompt.md, без пояснений вокруг и без оболочки из тройных кавычек.
3. Запусти проверку одной командой из корня репозитория:
   `node scripts/primitives-lab/check.mjs {{surface}} {{dir}}`
4. Если проверка печатает проблемы, исправь `{{dir}}/answer.{{ext}}` по ним и запусти ту же команду снова. Исправлять можно не больше двух раз, то есть проверка запускается не больше трёх раз. Если проверка печатает «Готово», остановись. Если она пишет, что это сбой стенда (завершается с кодом 2), это не попытка и не твоя ошибка: ответ не трогай и запусти ту же команду ещё раз, до двух повторов подряд.
5. Не создавай, не правь и не удаляй никакие другие файлы. Не запускай другие команды. Не пытайся обойти проверку и не редактируй её вывод.
6. Закончи ровно одной строкой: «Готово» или «Не вышло: <слой или правило из последней проблемы>». Больше ничего не пиши.

# Листок: каркас учёта закупок

## Что входит в первую версию

- каталог продуктов;
- создание продукта с категорией и единицей измерения;
- создание запроса на закупку из каталога;
- ответ на запрос: фактическое количество и цена по каждой позиции;
- статусы «Нужно купить» и «Куплено»;
- итоговая сумма закрытой закупки;
- авторизация и адаптивный интерфейс, который можно установить на телефон.

## Технологии

- **Интерфейс:** Next.js / React и Vinext.
- **Размещение:** Cloudflare Workers через Sites.
- **Авторизация:** Sign in with ChatGPT, управляемая платформой; приложение не хранит пароли.
- **Первая версия данных:** localStorage для мгновенно работающего прототипа без отдельного бэкенда.
- **Синхронизация:** Google Sheets API можно подключить следующим слоем. Таблица будет хранить продукты, заявки и строки покупок.
- **Telegram:** необязательный модуль уведомлений; не участвует в основных сценариях.
- **Мобильный доступ:** PWA. Один код работает как сайт и как устанавливаемое приложение.

## Модель данных

- `Product`: название, категория, единица измерения.
- `PurchaseRequest`: название, дата, статус, список нужных продуктов и количеств.
- `Purchase`: фактическое количество и цена каждой купленной позиции.

## Пользовательский путь

1. Пользователь добавляет продукты в каталог.
2. Выбирает нужные количества и создаёт запрос.
3. Покупатель открывает запрос и нажимает «Ответить на запрос».
4. Вводит фактические количества и цены.
5. Запрос закрывается, а интерфейс показывает итоговую сумму.

## Путь к боевой версии

Для общего доступа с нескольких устройств localStorage нужно заменить на синхронизацию с Google Sheets либо D1. Интерфейс и модель данных менять не потребуется: достаточно заменить слой хранения.

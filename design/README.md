# Дизайн-мокапы Cookish

Статичные HTML/CSS-экраны для итераций над дизайном интерфейса. Никакой логики
и бэкенда: данные примера вписаны прямо в разметку, правки вносятся в HTML
и CSS без риска для приложения.

## Запуск

```powershell
npm run design
```

Откроется `http://127.0.0.1:4173/` — галерея всех экранов. Каждый экран
открывается отдельно по ссылке; разметка экранов лежит в `design/screens/`.

## Обратная связь через Orca

1. Откройте нужный экран во встроенном браузере Orca.
2. Включите в панели браузера Orca режим аннотирования: клик по элементу →
   комментарий. Так по элементу на экране.
3. Когда всё отметили — кнопка «Copy all feedback» в трее аннотаций.
4. Скажите агенту «забери обратку» — он прочитает аннотации из буфера обмена
   и внесёт правки в мокапы.

## Как это устроено

- `css/cookish.css` — копия актуальных стилей приложения из `mobile-shell/`
  на момент создания песочницы. Дальше живёт своей жизнью: редизайн
  начинается здесь, а не в `styles.css`.
- `css/screen-frame.css` — только для песочницы: показывает мобильный экран
  колонкой в настольном браузере.
- `screens/*.html` — статичные копии экранов с примерами данных.
- `scripts/serve-design.mjs` — маленький статический сервер (`npm run design`).

Когда дизайн утверждён, экран переносится в `mobile-shell/` вместе с логикой,
юнит- и Playwright-тестами — мокапы продолжают оставаться площадкой для
следующих итераций.

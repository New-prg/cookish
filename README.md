# Листок

Учёт продуктов, запросов на закупку и фактических трат.

## Android

Android-приложение автономно: интерфейс и данные находятся на телефоне. Docker,
локальный сервер и файл `.env` для его работы не нужны. Подключённая Google
Таблица обновляется после изменений и фоновой задачей WorkManager каждые
15 минут при наличии сети.

Сборка:

```powershell
npm install
npm run android:apk
```

Готовый файл: `output/Listok-debug.apk`.

Для Google-входа и Google Sheets в Google Cloud должны быть:

1. Включён Google Sheets API.
2. Создан OAuth-клиент типа Android.
3. Package name: `ru.listok.purchases`.
4. SHA-1 debug-сертификата:
   `90:4F:BD:1C:8B:33:D5:7E:96:82:CD:26:F9:48:06:F9:D5:3A:39:9E`.
5. На экране согласия добавлены scopes:
   `openid`, `userinfo.email`, `userinfo.profile`, `spreadsheets`.

Client Secret для Android-приложения не используется.

В профиле можно создать или подключить таблицу, открыть её для редактирования
в Google Sheets и отправить ссылку через системное меню Android.

Для совместной работы оба пользователя подключают одну и ту же Google Таблицу.
Приложение объединяет записи по идентификатору и времени изменения. Новые
активные запросы другого пользователя показываются системным уведомлением
после фоновой проверки. На Android 13+ необходимо разрешить уведомления.
Пока приложение открыто, общая таблица синхронизируется каждые 5 секунд;
после сворачивания используется фоновая проверка.
Один продукт может присутствовать в запросе только один раз; повторяющиеся
строки старых запросов и покупок удаляются при следующей синхронизации.

### Схема синхронизации

Версию 5.0 необходимо установить на все устройства, подключённые к общей
таблице, до продолжения работы. Версии 4.x используют старую структуру листов и
не должны синхронизироваться с таблицей после её перевода на новую схему.

Перед отправкой приложение формирует нормализованный пакет:

1. Продукты и запросы дедуплицируются по `id`.
2. Позиции запроса дедуплицируются по `productId`.
3. Каждый ответ имеет отдельный `response_id`; его позиции дедуплицируются по
   `productId`.
4. Повторная отправка того же `response_id` обновляет ответ по времени
   изменения. Другой `response_id` сохраняется как дополнительный ответ.
5. Текущий остаток вычисляется как базовый остаток плюс количества из всех
   ответов, созданных после фиксации базового остатка.

Старые строки листа «Покупки» автоматически преобразуются в один совместимый
ответ на запрос. Ручное изменение остатка продукта создаёт новую базовую точку:
изменения более старых ответов после этого не меняют текущий остаток. При
одновременном редактировании одного объекта на двух устройствах используется
последняя версия по времени изменения; разные ответы объединяются и не
перезаписывают друг друга.

### Обработанные пограничные случаи

- Повторная отправка одного ответа безопасна: одинаковый `response_id` не
  увеличивает остаток повторно.
- Два ответа на один запрос сохраняются отдельно, их количества и цены
  суммируются.
- Редактирование ответа заменяет только его прежнюю версию; остальные ответы
  не изменяются.
- Новый дополнительный ответ открывается с нулевыми количествами, чтобы
  случайно не повторить предыдущую закупку.
- Товар с ненулевым количеством или ценой в ответе нельзя удалить из запроса.
- Редактирование старого запроса не пересчитывает текущий остаток задним
  числом.
- Ручное редактирование остатка продукта создаёт контрольную точку и исключает
  повторное применение более старых ответов.
- Ответ с нулевым количеством сохраняется, но не меняет остаток; пустая цена
  считается нулевой.
- После работы без сети разные ответы объединяются при следующей синхронизации.
  При конфликте правок одного и того же ответа побеждает версия с более поздним
  временем изменения.

## Веб-версия

Запуск через Docker:

```powershell
Copy-Item .env.example .env
docker compose up --build -d
```

После запуска сайт доступен на `http://localhost:3000`.

Для веб-версии требуется отдельный OAuth-клиент типа Web application.
Redirect URI: `http://localhost:3000/api/auth/google/callback`.

Остановка:

```powershell
docker compose down
```
